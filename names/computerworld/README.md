# computerworld

ComputerWorld: deterministic synthetic computers (five OS shells, real applications, a synthetic internet, byte-identical replay). The engine's Rust crate will be published under this name; its source is https://github.com/ComputaCo/computerworld-engine (MIT).

This is version 0.0.1. It holds the name `computerworld` for ComputaCo and has no functions yet: it is not a working
package. The real code will be published under this name in a later version.

- ComputaCo: https://computaco.ai
- The hosted API's clients today: `computerworld-cloud` on npm and PyPI (https://github.com/ComputaCo/computerworld)
- The open engine: https://github.com/ComputaCo/computerworld-engine
