# computaco

ComputaCo's own package. ComputaCo makes ComputerWorld, a simulator of whole computers that agents learn and are tested in, and Computatrum, an agent that uses a computer for you.

This is version 0.0.1. It holds the name `computaco` for ComputaCo and has no functions yet: it is not a working
package. The real code will be published under this name in a later version.

- ComputaCo: https://computaco.ai
- The hosted API's clients today: `computerworld-cloud` on npm and PyPI (https://github.com/ComputaCo/computerworld)
- The open engine: https://github.com/ComputaCo/computerworld-engine
