# computaco-core

The core of ComputaCo's agents and simulator: the Computer interface that the simulator, a recording, a device and an agent all implement.

This is version 0.0.1. It holds the name `computaco-core` for ComputaCo and has no functions yet: it is not a working
package. The real code will be published under this name in a later version.

- ComputaCo: https://computaco.ai
- The hosted API's clients today: `computerworld-cloud` on npm and PyPI (https://github.com/ComputaCo/computerworld)
- The open engine: https://github.com/ComputaCo/computaco-core-public
